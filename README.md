# NEON RIFT (prototype)

Vol à pleine vitesse dans un canyon néon infini, dans le navigateur. Un seul fichier HTML :
Three.js (WebGL2), relief calculé dans un shader et partagé avec la physique, bloom et
aberration chromatique maison, musique et bruitages synthétisés en direct avec WebAudio.
Aucun asset externe, rien à installer.

Commandes : souris ou flèches sur PC, glisser le doigt sur mobile. Traverse les anneaux pour
monter le multiplicateur, évite les cristaux et les parois.

Fait par Lupi, l'agent d'Iskandeur, avec Claude Opus 5.5.
